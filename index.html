Construction Gauthier · générer, réviser/rebalancer, rattacher au WBS, puis exporter pour Maestro

1 Numéro de projet Maestro

Ce code sera inscrit dans la colonne « Code projet » de chaque ligne du gabarit. Vérifiez-le deux fois — un mauvais numéro importe le budget dans le mauvais dossier Maestro.

2 Export CSV détaillé de l'estimation

📄
Glissez le fichier Sections.csv ici, ou cliquez pour le choisir

Export « CSV détaillé » de l'Estimateur Général (clic droit dans le tableau des sections). Le fichier reste sur votre poste — aucun envoi sur Internet.

Recopiez le Sous total affiché à l'écran de fermeture, avant administration et taxes. L'outil compare et vous avertit. Ce seul contrôle attrape les deux pannes qui comptent : un export incomplet, et surtout un mauvais fichier ou un mauvais numéro de projet.

Accepte l'export JSON de l'app WBS, ou un fichier à deux colonnes : code MF/activité ; code de lot (No OTP). Sans ce fichier, le No OTP reste vide (saisie manuelle possible).

Le fichier DDN_Gauthier_2026 tel quel. Il sert à nommer les activités créées par regroupement et à signaler celles qui n'existent pas encore au dictionnaire — un avertissement, pas un blocage : Maestro crée l'activité qu'on lui donne. Sans ce fichier, les noms par défaut de l'outil s'appliquent et aucune validation n'est faite.

3 Générer

Règles : une ligne par activité × groupe · pose → L Salaire (heures, HRE) · achat → M Matériaux · équip. → E Équipement · sous-traitant → S Sous-traitants · divers → D Divers.
Relevés de quantités : les composants d'un assemblage sans code MasterFormat sont regroupés par famille et posés sur l'activité du DDN : gypse, vis et coins → 09 21 16.01 · stud, lisse, résilient, sablière → 09 22 16.01 · laine → 07 21 16.02 (.01 si l'assemblage d'origine est un mur extérieur) · ruban et scellant coupe-feu → 07 84 00.03. La surface de l'assemblage est reportée en pi.ca comme quantité à réaliser. Une famille non reconnue reste sur le code de sa section et est signalée.
