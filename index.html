Estimation classe A → Gabarit budget Maestro

Construction Gauthier · générer, réviser/rebalancer, rattacher au WBS, puis exporter pour Maestro

1 Numéro de projet Maestro

Ce code sera inscrit dans la colonne « Code projet » de chaque ligne du gabarit.

2 Export CSV détaillé de l'estimation

📄
Glissez le fichier Sections.csv ici, ou cliquez pour le choisir

Export « CSV détaillé » de l'Estimateur Général (clic droit dans le tableau des sections). Le fichier reste sur votre poste — aucun envoi sur Internet.

Accepte l'export JSON de l'app WBS, ou un fichier à deux colonnes : code MF/activité ; code de lot (No OTP). Sans ce fichier, le No OTP reste vide (saisie manuelle possible).

3 Générer

Règles : une ligne par activité × groupe · pose → L Salaire (heures, HRE) · achat → M Matériaux · équip. → E Équipement · sous-traitant → S Sous-traitants · divers → D Divers.

4 Réviser / rebalancer / rattacher au WBS

Ajustez montants et heures (rebalancement), redistribuez des lignes vers un autre code, et vérifiez le No OTP (lot WBS). Le gabarit téléchargé contient les valeurs ajustées.
